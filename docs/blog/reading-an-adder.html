MODEL WALKTHROUGH · ADDER LENS

Reading an addition network

Daniel Jackson · Synaptic Lens

A small neural network learns addition. A second network learns to predict when it gets the answer right.

That is the idea behind the featured Adder Lens. It examines an addition network alongside a particular arithmetic query and estimates the probability that the network will answer correctly. Looking across many networks and stages of training gives us a detailed view of how the reader tracks a learned capability.

Start with something we can inspect

The target is a fully connected network with 20 inputs, 32 hidden ReLU units, and 19 outputs. Two one-hot digit encodings represent the input pair. The outputs represent the possible sums, from 0 through 18.

There are 100 ordered pairs of single digits. We can evaluate every one of them, including the cases a partly trained network still gets wrong. The released population contains two training rules and eight training ages for each target-root family. Related states stay together when the population is partitioned for training and evaluation.

What the Lens reads

The reader receives the target’s weights and biases, the arithmetic query, and the hidden activations produced by that query. Preprocessing puts the target coefficients into a consistent scale and applies normalization fitted on the training partition.

The Lens combines information about hidden neurons and their output connections into scores for the possible answers. The difference between the expected answer’s score and the strongest rival becomes a correctness probability through a sigmoid. The target’s output logits are excluded from the reader inputs.

For a query such as 3 + 6, the useful question is specific: how likely is this particular target network, at this point in training, to answer correctly?

The featured checkpoint

The walkthrough uses SYN88 trajectory seed 27 at update 17,000. It had the lowest saved validation objective among the three released trajectory checkpoints. That gives us a fixed selection rule for the public example.

99.6167% correctness-prediction accuracy across 819,200 query predictions in the saved evaluation.

The evaluation covers 512 independent target-root families, two rules, and eight ages. Its macro Brier score is 0.002976; lower scores indicate better probability predictions.

This evaluation measures transfer across independent target roots using the complete 100-query arithmetic suite. The targets themselves train on that same suite. The benchmark record contains the metric definitions, selection details, and evidence identities.

Try it yourself

The Adder Lens walkthrough downloads the featured reader and one target-root family from pinned Hugging Face revisions, checks their hashes, and runs inference.

  1. Follow the repository’s download setup.
  2. Run the commands in the Adder walkthrough. CUDA is the default; --device cpu runs the small example on a CPU.
  3. Compare target addition accuracy with Lens correctness-prediction accuracy and Brier score across the training ages.

The default root is fixed as 0000, so everyone starts with the same sample. Its output describes that root’s 1,600 queries. The larger benchmark above summarizes the full saved evaluation.

A useful first experiment is to change the target root while keeping the Lens checkpoint fixed. Inspect which ages contain mistakes, whether the reader identifies them, and how its confidence changes as the target learns.

Why this example matters

Addition gives us a compact setting where the target’s behavior is easy to measure and the reader’s inputs are explicit. The model, target population, inference code, and evidence can travel together. That makes it a practical starting point for experimenting with learned readers.
