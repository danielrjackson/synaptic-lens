# SYN88 target population: generation and evaluation

SYN88 is the historical paired-rule adder lifetime study. Its complete published
population contains **2,304 independent root families**, with two training rules
and eight recorded ages per root. Paired rules start from identical weights;
these are not 36,864 unique independently initialized networks.

## Generate new target lifetimes

Install this repository's dependencies, then run:

```console
python -m synaptic_lens.syn88_targets ./generated-targets --count 1
python -m synaptic_lens.syn88_targets ./full-population --count 2304 --device cuda
```

Use a fresh output directory. Existing files are never replaced. The default is
one root on CPU so a quickstart does not inadvertently launch the full study.
This compact implementation intentionally omits the archival optimizer/RNG
resume snapshots: an interrupted generation should be retried in a new folder.

Each target is a 20 -> 32 ReLU -> 19 MLP. Inputs are the concatenated one-hot
representations of all 100 ordered digit pairs. Training uses full-batch cross
entropy and Adam at learning rate 0.02 for 100 updates. The rules are addition
and `(2*a+b+1)%19`. Both use root seed `492232 + root_index`. Checkpoints are at
updates 0, 1, 2, 5, 10, 25, 50 and 100. Labels saved as `addition_correct` always
measure addition, including for targets trained on the alternate rule.

The recipe derives from the archived SYN88 generation implementation. Numerical
results may vary across PyTorch releases, devices and kernels; newly generated
weights are not replacements for the historical checkpoints. To reproduce
historical evaluation, use the released population and its manifest hashes.

## Portable checkpoint format

Each `root-NNNN.npz` can be opened with `numpy.load(..., allow_pickle=False)`:

- `weights`: float32 `[2, 8, 1299]`, rule then checkpoint age.
- `addition_correct`: uint8 `[2, 8, 100]`, ordered-pair correctness.
- `root_index`, `root_seed`: scalar int64; `ages`: int64 `[8]`.

Flattened parameter order is `hidden.weight` (32x20), `hidden.bias` (32),
`output.weight` (19x32), `output.bias` (19). The published export manifest binds
source and exported hashes. Its quickstart reconstructs native predictions and
checks saved labels. Numeric NPZ exports contain no optimizer or RNG objects.

## Evaluation protocol and limits

Root split seed 880088 assigns 1,536 roots to train, 256 to validation and 512 to
test using `torch.randperm`. All ages and both rules of a root stay together.
Never randomly split individual states: doing so would leak shared initialization
and training trajectories between partitions. `root-splits.json` generated here
lists all assignments even when generating only a quickstart subset.

The SYN88 reader receives target coefficients, the arithmetic query and
query-aligned hidden ReLU activations; it is not a weights-only reader. Target
output logits and correctness labels are not input features. Native execution
supplies supervision and audit measurements. Since the
100 digit pairs are also used to train each target, target accuracy on this suite
is not evidence of generalization to unseen inputs. Lens evaluation instead
measures transfer across independent target roots. Test results are historical,
already examined results, not a newly sealed benchmark. Compare existing Lens
predictions with the recorded per-pair labels using the existing trajectory
loader and inference example; keep metric denominators and root partition explicit.

The earlier four-root smoke sample is not a substitute for the complete study.
No sealed early SYN53 holdout is included or regenerated by this module. MNIST
and adder studies remain separate; see their milestone pages for distinct data,
partitions and limitations. Image-fed Lens experiments are not part of this release.
