Where this example comes from

Target root 896, addition rule. This is the first target in the fresh no-sort final evaluation, using preselected seed 161120 and every physical neuron mask. No score ranking was used.

The target has 20 inputs, 32 ReLU hidden neurons, and 19 outputs. Each mask removes one complete 40-value neuron bundle. Some removals leave the answers unchanged; others change the target's behavior. Every case remains available here.

How the reader and wrapper work

Weights are normalized in the original neuron order. No parameter-dependent sorting is performed. The primary Lens uses no positional embeddings, and training includes random neuron permutations. Predictions are returned for a masked physical neuron.

The wrapper retains the hidden neuron's true positive normalization scale outside Lens, then uses it to convert the predicted normalized bundle back into original coordinates. Only that neuron is replaced; all other weights retain their original order.

The shuffle button demonstrates display reordering only. The saved evaluation separately reindexed targets and mapped their predictions back to the same physical neurons. Its maximum prediction difference is shown below for learned readers.
