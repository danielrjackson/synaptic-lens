# Website source and publishing

The website, blog, and interactive demonstrations are maintained in [synaptic-lens-website](https://github.com/danielrjackson/synaptic-lens-website).

The public address remains https://danielrjackson.github.io/synaptic-lens/.

This repository retains the library, training and inference examples, technical guides, model-download manifests, and research evidence. Its `Publish website` workflow checks out the website source and includes these technical documents in the published output. It checks for website changes every 15 minutes, runs after changes to technical docs, and can be run manually. No new credentials are needed.

Edit site pages in the website repository. Daniel reviews and approves blog posts before publication. See the website README for the preview and validation commands.
